QOTD

Applies instantly to open Newton tabs. Token stays in your browser — the only network calls go to the my.newtonschool.co API.

01 / Attendance

Overall percentage, bunks left before your threshold, per-subject breakdown — pulled straight from the portal's own numbers, nothing guessed.

02 / Alerts

Everything ranked by urgency. Overdue first, then what's closing in, then anything live. One list, no digging through tabs.

03 / Tasks

Assignments, classes, contests, QOTD in one scroll. Auto-detected items are flagged so you know which ones to double-check.

04 / Settings

Digest time, thresholds, quiet hours, per-feature sync toggles, and a portal theme switcher that recolors my.newtonschool.co itself.

WHAT IT WATCHES

Five things it tracks. One thing it saves: your time.

01

Attendance + bunk count

Live percentage, per-subject breakdown, and exactly how many classes you can skip before you cross your own 75% line.

02

Assignment deadlines

24-hour, 1-hour, and overdue nudges, pulled from the portal and sorted so the most urgent one sits on top.

03

Classes & join links

A heads-up 10 minutes before a timetable class, with the join link already in the notification.

04

Coding contests

A ping the moment a contest goes live, plus what's coming up so you can actually plan your week around it.

05

QOTD streak nudges

An evening reminder if today's Question of the Day is unsolved — Bearer token when you're signed in, anonymous fallback when you're not.

06

Portal theme switcher

Light, dark, warm, or auto — recolors the whole my.newtonschool.co page instantly, not just the popup.

GET IT RUNNING

Four steps. No store listing, so it loads unpacked.

Same steps in Opera GX and Chrome — both read the same Manifest V3 format.

1

Download and unzip

Grab the same ZIP from the hero section, unzip it somewhere permanent — the browser keeps pointing at that exact folder, so don't move it afterward.

./nst-reminder-extension-v0.2.0.zip
2

Turn on Developer Mode

Open your extensions page and flip the switch in the top corner.

opera://extensions chrome://extensions
3

Load unpacked

Click "Load unpacked" and select the folder with manifest.json in it — not the ZIP itself. Pin NST Reminder to the toolbar when prompted.

4

Log in once

Open my.newtonschool.co and sign in as usual. The extension picks up your session token automatically — nothing to paste, no password stored anywhere.
